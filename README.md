## The entry

One word describing the boss:

```
reply-all
```

## How it works

`main.ts` writes exactly that one word — 9 characters, no spaces, no
newline — to `/output/entry.txt`, then reads the file back to verify it
holds exactly the word the sealed scorer gates on (UTF-8 text, 1–30
characters, not only whitespace).

Run it with Node 22+:

```sh
node main.ts
```
